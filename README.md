# LocalTruck : site publié

Ce dépôt contient uniquement la version publiée du site https://localtruck.fr/ (branche `gh-pages`) et, sur la branche `main`,
le petit programme qui refait chaque nuit les pages « food trucks par ville » à partir des fiches visibles de tous.

Pour toute question ou demande de retrait d'une fiche : contact@localtruck.fr
